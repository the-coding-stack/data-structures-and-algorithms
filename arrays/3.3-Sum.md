# 3Sum

## Problem

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j], nums[k]]` such that the three indices are distinct and the values sum to `0`. The result must not contain duplicate triplets. The order of the triplets does not matter.

### Examples

**Example 1**

```text
Input:  nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
Explanation: Both distinct triplets sum to zero.
```

**Example 2**

```text
Input:  nums = [0, 1, 1]
Output: []
Explanation: No three values sum to zero.
```

**Example 3**

```text
Input:  nums = [0, 0, 0]
Output: [[0, 0, 0]]
Explanation: There is one unique triplet, even though all values are equal.
```

### Constraints

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## Approach: Sorting and Two Pointers

Sort the array, then choose each value in turn as the first value of a triplet. For each choice, use two pointers on the remaining suffix. If the sum is too small, move the left pointer forward; if it is too large, move the right pointer backward. When the sum is zero, record the triplet and skip repeated values so the result stays unique.

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    left++;
                } else if (sum > 0) {
                    right--;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    left++;
                    right--;

                    while (left < right && nums[left] == nums[left - 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right + 1]) {
                        right--;
                    }
                }
            }
        }

        return result;
    }
}
```

**Complexity**

- **Time:** `O(n^2)`. Sorting takes `O(n log n)` and the two-pointer scan takes `O(n^2)`.
- **Auxiliary space:** `O(log n)` for the sorting implementation's stack, excluding the returned list. The output can contain `O(n^2)` triplets in the worst case.
