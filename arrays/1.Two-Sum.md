# Two Sum

## Problem

Given an integer array `nums` and an integer `target`, return the indices of two distinct elements whose values add up to `target`.

You may assume that exactly one solution exists. The answer can be returned in either order.

### Examples

**Example 1**

```text
Input:  nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
Explanation: nums[0] + nums[1] = 2 + 7 = 9.
```

**Example 2**

```text
Input:  nums = [3, 2, 4], target = 6
Output: [1, 2]
Explanation: nums[1] + nums[2] = 2 + 4 = 6.
```

**Example 3**

```text
Input:  nums = [3, 3], target = 6
Output: [0, 1]
Explanation: The two equal values are at different indices.
```

### Constraints

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- Exactly one valid answer exists.
- The same array element cannot be used twice.

## Approach 1: Brute Force

Try every pair of distinct elements. For each index `i`, check every later index `j`. Return the pair as soon as their values add up to the target.

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[] {i, j};
                }
            }
        }

        // The problem guarantees a solution, so this line is unreachable.
        return new int[0];
    }
}
```

**Complexity**

- **Time:** `O(n^2)` in the worst case, because every pair may be checked.
- **Auxiliary space:** `O(1)`, excluding the two-index result.

## Approach 2: One-Pass Hash Map

For each value, calculate its complement: `target - nums[i]`. Store each previously seen number and its index in a hash map. If the complement is already in the map, the two indices form the answer. Checking before inserting the current value ensures an element is never paired with itself; storing indices also handles duplicate values correctly.

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> indexByValue = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];

            if (indexByValue.containsKey(complement)) {
                return new int[] {indexByValue.get(complement), i};
            }

            indexByValue.put(nums[i], i);
        }

        // The problem guarantees a solution, so this line is unreachable.
        return new int[0];
    }
}
```

**Complexity**

- **Time:** `O(n)` on average, with one hash map lookup and insertion per element.
- **Auxiliary space:** `O(n)` in the worst case for the hash map.

The hash map approach meets the follow-up requirement of better than `O(n^2)` time.
